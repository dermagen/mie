# PDF курса MIE

Эта папка содержит готовый PDF, снимок HTML, сборщик и свободные запасные шрифты. Скрипт использует печатные стили HTML, сохраняет текст и внутренние ссылки; страницы формата A4. Файлы первоисточников PDF не затрагиваются.

## Быстрый запуск

Нужны Python 3.10 или новее, Perl и зависимости WeasyPrint (в том числе Pango и необходимые системные библиотеки). Например, в Debian/Ubuntu:

```sh
sudo apt install python3 python3-venv perl libpango-1.0-0 libpangoft2-1.0-0 libharfbuzz-subset0 libffi-dev
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r pdf/requirements.txt
python pdf/build_pdf.py
```

Команды приведены из корня проекта, где папки `mie/`, `tools/`, `lexicon/` и `pdf/` лежат рядом. Для сборки HTML дополнительно нужны зависимости самого курса (в частности, Python-модули его транскриптора). При запуске скрипт **сначала пересобирает HTML** из `mie/src/`, затем создаёт `pdf/MIE-kurs.pdf`; ошибки сборки не заменяют существующий PDF. Запуск повторяется после каждой серии правок. Сам HTML не изменяется средствами PDF-сборки; при обычном запуске его обновляет штатный сборщик курса.

Чтобы использовать уже готовый HTML без пересборки:

```sh
python pdf/build_pdf.py --html-only
```

Можно указать любой HTML и имя результата:

```sh
python pdf/build_pdf.py --input /путь/к/курсу.html --output /путь/к/курсу.pdf
```

Папка работает и отдельно от проекта: если `mie/src/build.pl` рядом нет, автоматически используется приложенный `pdf/MIE-kurs.html`. Замените этот снимок актуальным HTML после правок или укажите его через `--input`. В автономном режиме Perl и исходники проекта не нужны. На Windows/macOS используйте аналогичные команды Python и установите системные зависимости WeasyPrint согласно [официальной инструкции](https://doc.courtbouillon.org/weasyprint/stable/first_steps.html#installation). Версия WeasyPrint зафиксирована для воспроизводимости; на Windows активируйте окружение командой `.venv\Scripts\activate`.

## Шрифты

Желаемый порядок задан в HTML: **Cambria → Tinos → Times New Roman** для основного текста и **Calibri → Arimo → Arial** для заголовков. Если Cambria и Calibri установлены в системе, WeasyPrint использует их в доступных начертаниях. Для локального использования можно поместить законно полученные файлы в `fonts/microsoft/`:

| Семейство | Обычный | Курсив | Полужирный | Полужирный курсив |
|---|---|---|---|---|
| Cambria | `cambria.ttc` или `cambria.ttf` | `cambriai.ttf` | `cambriab.ttf` | `cambriaz.ttf` |
| Calibri | `calibri.ttf` | `calibrii.ttf` | `calibrib.ttf` | `calibriz.ttf` |

На Linux имена файлов чувствительны к регистру. Microsoft-шрифты в комплект **не включены**: их распространение и использование определяются вашей лицензией. Если установлены не все начертания или отсутствуют отдельные символы, могут использоваться заменители. Проверить реальные встроенные шрифты можно командой `pdffonts pdf/MIE-kurs.pdf` (если установлен Poppler).

Свободные Tinos и Arimo включены в `fonts/fallback/` вместе с лицензиями SIL Open Font License. Arimo преобразован из переменных шрифтов Google Fonts в статические начертания 400/700. Во время создания PDF доступ к сети отключён. Для некоторых редких знаков система может подставить ещё один шрифт, поэтому нужен установленный шрифт с расширенной кириллицей и диакритикой, например DejaVu Sans.

## Проверка

Скрипт проверяет наличие страниц и внутренних PDF-ссылок, но это не заменяет просмотра всех страниц: PDF-движок может переносить строки и разбивать страницы иначе, чем браузер, а замена шрифтов меняет вёрстку. В конце сборки указаны число страниц и ссылок. В предупреждениях WeasyPrint о `@media screen`, `overflow-x`, `max-content` и `margin-inline` речь идёт о неподдерживаемых экранных или отдельных CSS-свойствах; для печатного содержания добавлено отдельное правило. После смены шрифтов стоит проверить содержание, таблицы, переносы, указатель и отдельные ссылки.
